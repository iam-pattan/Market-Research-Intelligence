            Copy the folder into your Claude Code skills directory, then invoke it with a lead name and intent to contact.

            cp -r skills/banyan-sales-pitch ~/.claude/skills/

            Every pitch returns subject · body (50–125 words) · personalization_note · thesis · send_recommendation.

            Access gate

            Lead identity + pitch content is Sales/BD data. Output must pass policy.guard(role, …); Data Science and Finance never receive it. See the companion Layered Data Access Architecture page.

            Method, validation & caveats

            How every number on this page was produced, and how far it can be trusted.

            Pipeline

            Deterministic scoring core, separate from the LLM: extractors propose per-criterion scores with confidence; the rubric engine alone computes the tier.
            codex web_search discovery (12 vertical batches)→333 records→ingest → CriterionScore × confidence→rubric_engine: composite → discount → gates → tier→curate top 250→25 deep dossiers + pitches→3-pass triangulation→2 QC rounds + grounding check

            Banyan rubric (config/banyan.yaml)

            Weights derived from Banyan's stated criteria (banyansoftware.com/faq, self-reported). Defaults — tunable.

            Growth rubric (config/growth.yaml)

            Contrast rubric for scaling / VC-backed companies. Not Banyan's thesis — used to catch non-targets.

            Confidence discount

            adjusted = composite × (floor + (1 − floor) × overall_confidence)
            floor = 0.5 → an unverifiable company can lose at most half its composite
            Gates: loss evidence → REJECTED · revenue < $2M → cap tier C · coverage < 50% → INSUFFICIENT_DATA

            This is why genuine private targets land at tier C: profitability and retention are rarely verifiable from the public web, so confidence is low and the score is discounted. Tier C flags "verify in diligence", not "bad fit".

            Validation

            Triangulation (3 independent discovery passes)

            Pass 1 vertical discovery · Pass 2 acquirer-adjacency · Pass 3 OSINT/registries. A coverage-and-ownership check, not financial verification — except where registries hold filed accounts (UK Companies House, EU registries).

            What the data can and cannot say

            • Revenue figures are web-research estimates (Growjo/Owler/codex) at ~0.25–0.55 confidence — directional, never underwrite from them.
            • Margin / profit are not available as numbers for private companies. The screen carries a profitability signal (0–1 score + confidence + loss-evidence flag); real PBT exists only where accounts are filed (e.g. UK/EU registry names surfaced in pass 3).
            • Ownership calls are time-sensitive; 11 false "founder-owned" labels were caught in triangulation (e.g. Vagaro = PE, Agiloft = FTV). Confirm cap tables before outreach.
            • Banyan's "120+ acquired / 0 sold" is self-reported positioning, not audited.
            • Sources: public web + official registries only. No PitchBook, Crunchbase or Grata.
